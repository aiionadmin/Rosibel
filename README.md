# Rosibel Pedras

Site institucional estático (HTML único).

## Preview local

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

Abra http://localhost:3000

## Arquivos

- `index.html` — site completo (layout, estilos e scripts embutidos)
- `links/` — linktree próprio (mesmos contatos do linklist.bio, visual do site)

## Deploy

Push para GitHub. Deploy no VPS só quando solicitado.
